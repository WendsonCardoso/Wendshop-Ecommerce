🛍️ Wendshop E-commerce

Projeto de uma landing page de e-commerce moderna, com foco em design profissional, experiência do usuário e simulação de uma loja virtual.

🔗 Acesse o projeto:
https://wendsoncardoso.github.io/Wendshop-Ecommerce/

🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

HTML5
CSS3
JavaScript
💻 Projeto

O Wendshop E-commerce é uma aplicação front-end que simula uma loja virtual, apresentando produtos, interações com carrinho e um fluxo simples de compra.

O objetivo principal é criar uma interface moderna e funcional para demonstrar habilidades em desenvolvimento web.

🎨 Layout

O layout foi desenvolvido com foco em:

Interface moderna
Boa experiência do usuário (UX)
Design responsivo
Organização visual clara
📱 Responsividade

O projeto foi desenvolvido para funcionar em diferentes dispositivos:

Desktop
Tablet
Mobile
⚙️ Como executar
# Clone este repositório
git clone https://github.com/WendsonCardoso/Wendshop-Ecommerce.git

# Acesse a pasta do projeto
cd Wendshop-Ecommerce

# Abra o arquivo index.html no navegador
